## 🚀 How to Use New Features

### For Users:

1. **Contact Form:**
   - Add `[lead_form]` to any page
   - Drag and drop files
   - Get instant validation
   - Form auto-saves as you type

2. **Customization:**
   ```
   [lead_form 
     title="Get in Touch" 
     subtitle="We'd love to hear from you"
     show_file_upload="yes"
     show_budget="yes"
     show_timeline="yes"]
   ```

### For Admins:

1. **Dashboard:**
   - Go to **Leads** → **Dashboard**
   - View analytics and charts
   - Export leads to CSV
   - Search and filter leads

2. **Keyboard Shortcuts:**
   - `Ctrl/Cmd + E` - Export leads
   - `Ctrl/Cmd + /` - Focus search

3. **Quick Actions:**
   - Click email icon to send email
   - Click phone icon to call
   - Update status with dropdown
   - Copy shortcodes with one click
